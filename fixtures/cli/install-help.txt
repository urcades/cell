Usage:
  cell install <source> [-l]

Install a package and add it to settings.

Options:
  -l, --local    Install project-locally (.pi/settings.json)

Examples:
  cell install npm:@foo/bar
  cell install git:github.com/user/repo
  cell install git:git@github.com:user/repo
  cell install https://github.com/user/repo
  cell install ssh://git@github.com/user/repo
  cell install ./local/path
