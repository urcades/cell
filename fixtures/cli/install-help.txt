Usage:
  pi-rust install <source> [-l]

Install a package and add it to settings.

Options:
  -l, --local    Install project-locally (.pi/settings.json)

Examples:
  pi-rust install npm:@foo/bar
  pi-rust install git:github.com/user/repo
  pi-rust install git:git@github.com:user/repo
  pi-rust install https://github.com/user/repo
  pi-rust install ssh://git@github.com/user/repo
  pi-rust install ./local/path
